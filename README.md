# Kommunquiz

Ett quiz om Sveriges kommuner, byggt på öppna nyckeltal från [Kolada](https://www.kolada.se).

Hämta data med `python3 fetch_kolada.py`, bygg sidan med `python3 build.py` och öppna `index.html`.

Sidan byggs om och publiceras på GitHub Pages varje vecka av `.github/workflows/pages.yml`.

Källa: Kolada.
